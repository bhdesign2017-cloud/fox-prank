# 狐狸心理測驗整人網站設計規格

## 目標

建立一個以 iPhone 直式操作為優先的單頁心理測驗。使用者先完成五題「測出你是哪種狐狸？」測驗，接著嘗試按下查看結果按鈕；按鈕會逃跑並逐次顯示更欠揍的嘲諷。使用者最終能完成整人流程、看到真實測驗結果，並發現隱藏身分是「被耍狐狸」。

## 專案範圍

- 單一路由、無登入、無後端、無外部資料庫。
- 所有內容與狀態均在瀏覽器內執行。
- 主要支援 iPhone Safari，同時兼容一般手機與桌面瀏覽器。
- 不模仿真實系統警告、不索取個資、不使用會讓人誤以為裝置故障的訊息。

## 視覺方向

- 主色為奶油黃、狐狸橘與深咖啡，點綴酸綠與莓果紅。
- 風格為可愛、貼紙感、略帶街機遊戲氣氛；避免常見科技感漸層與制式卡片牆。
- 使用原創狐狸角色插畫作為開場與結果頁主視覺。
- 版面優先考慮單手操作、瀏海與 Home Indicator 安全區，以及小螢幕文字可讀性。

## 使用流程

### 1. 開場

- 標題：「測出你是哪種狐狸？」
- 副標：「五題就知道。大概啦。」
- 主要按鈕：「開始測驗」
- 顯示狐狸插畫與簡短的隱私提示：「不會偷看你的相簿，狐狸沒那麼閒。」

### 2. 五題測驗

- 每次只顯示一題，頂部呈現 1/5 至 5/5 進度。
- 每題四個選項，點擊後立即進入下一題。
- 題目圍繞週末習慣、手機用途、零食選擇、朋友邀約與遇到麻煩時的反應。
- 答案分數對應五種狐狸類型：
  - 睏睏狐狸：偏好休息、慢節奏與舒適圈。
  - 電動狐狸：偏好遊戲、挑戰與沉浸體驗。
  - 多力多滋狐狸：偏好零食、即時享樂與爽脆刺激；插畫不使用品牌商標或包裝。
  - 社交狐狸：偏好熱鬧、分享與朋友陪伴。
  - 探險狐狸：偏好新鮮感、行動與未知事物。
- 同分時由最後兩題的選擇決定，以避免隨機造成結果不一致。

### 3. 逃跑按鈕

- 五題完成後先顯示「狐狸 DNA 已解析」與主要按鈕「查看我的狐狸」。
- 在 iPhone 上，按鈕於 `pointerdown`／`touchstart` 發生時先移動，因此不依賴桌面 hover。
- 按鈕只能移動到安全可見區域，不可遮住關鍵文字、跑出螢幕或壓到瀏海與 Home Indicator。
- 前 7 次嘗試必定逃走；第 8 次開始速度降低並允許點中，確保整人有結束點。
- 每次失敗更新嘲諷文字並觸發輕微震動（裝置支援時），例如：
  1. 「差一點。真的只差一個太平洋。」
  2. 「你的手指還在載入嗎？」
  3. 「狐狸都等到睡著了。」
  4. 「需要幫你把按鈕放大到電視那麼大嗎？」
  5. 「這支手機是不是不認識你？」
  6. 「我開始替你感到尷尬了。」
  7. 「好啦，這次真的不跑。大概。」
- 若使用者開啟「減少動態效果」，移動改為短距離瞬移，不使用大幅彈跳動畫。

### 4. 第二層反轉

- 點中按鈕後進入「正在解密狐狸 DNA」假分析畫面。
- 進度快速走到 99%，停頓後顯示：「結果被狐狸叼走了。」
- 出現「長按 3 秒取回結果」控制項；進度第一次在 99% 失敗，顯示：「你放太早了。狐狸說的。」
- 第二次長按可成功完成，避免無限挫折。
- 長按過程必須能以觸控取消並重新開始，不鎖死頁面。

### 5. 真正結果

- 顯示實際計分所得的狐狸類型、原創插畫、三項性格描述與一段幽默吐槽。
- 再揭露隱藏稱號：「容易相信按鈕的被耍狐狸」。
- 提供「再測一次」與「複製整人連結」；不自動開啟系統分享面板。
- 複製失敗時改為顯示可手動複製的網址，不讓流程中斷。

## 互動與狀態

- 狀態分為：intro、quiz、escape、fake-analysis、hold、result。
- 重新整理會回到開場，避免朋友接手手機時看到上一個人的結果。
- 所有計時器與事件監聽在畫面切換時清理，避免重複觸發。
- 防止快速連點跳過題目；每題只能記錄一次回答。

## 響應式與無障礙

- 使用 `100dvh` 與 safe-area inset 處理 iPhone Safari 工具列變化。
- 文字對比符合 WCAG AA；互動區至少 44 x 44 px。
- 所有互動可由鍵盤完成；鍵盤使用者不執行逃跑機制，而以嘲諷提示加一次確認完成流程。
- 語意化標題、按鈕與進度資訊，避免把文字嵌進圖片。
- 音效預設關閉；本版不加入背景音樂。

## 技術方案

- 使用 React、TypeScript 與 Vite 建立單頁網站。
- 使用 CSS 動畫與瀏覽器 Pointer Events，不引入重量級動畫套件。
- 測驗題目、結果文案與嘲諷文案集中於獨立資料模組，方便日後調整。
- 原創插畫以專案內的壓縮圖片資產載入，並提供替代文字。
- 不使用遠端 API；建置後可部署為靜態網站。

## 驗證標準

- 以 390 x 844 與 393 x 852 的 iPhone 尺寸檢查完整流程。
- 五題均可作答，計分結果穩定，同一組答案每次得到同一類型。
- 逃跑按鈕前 7 次不可按中，第 8 次起可完成，且所有位置都在安全範圍內。
- 第二層第一次長按失敗、第二次成功，最後一定能看到真實結果。
- Safari／Chrome 觸控事件不造成頁面縮放、誤捲動或選取文字。
- `prefers-reduced-motion` 與鍵盤流程可正常完成。
- 生產建置成功，瀏覽器主控台無錯誤。
